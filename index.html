HARDWARE SPECIFICATIONS

NXP FRDM-MCXW71 Pin Connections

1. Female 3.5mm AUX Connector Interfacing (Audio In & Push-to-Talk)

Connects standard 3.5mm TRS / TRRS audio cables or external microphones to the FRDM-MCXW71 board:

AUX Connector Pin Signal Function FRDM-MCXW71 Pin Arduino Header Circuit Description
Tip Audio Left / Mono In PTA16 A0 LPADC0 Channel 0 (AC-coupled via 10µF cap, 10k/10k bias to 3.3V)
Ring 1 Audio Right / Jack Detect PTA21 D2 GPIO Digital Input with internal pull-up (detects cable insertion)
Ring 2 Ground GND GND Common Analog & Digital Ground reference
Sleeve Mic / Inline PTT Button PTB0 D4 GPIO Digital Input with internal pull-up (Active LOW on button press)

2. Speaker & Audio Output Interfacing

Drives an 8Ω 1W-2W speaker via PAM8403 Class-D amplifier or MAX98357A I2S amplifier:

Component Pin Signal Function FRDM-MCXW71 Pin Arduino Header Circuit Description
Amp Audio IN+ PWM Audio Output PTB1 D3 CTIMER0 PWM Match 1 output (through 1kΩ + 10nF RC low-pass filter)
Amp SHDN / Mute Amplifier Mute PTB2 D5 GPIO Output (High = Active / Unmute, Low = Shutdown / Anti-pop)
Amp VDD Power Supply (5V / 3.3V) 5V / 3.3V 5V / 3.3V Direct power rail from FRDM board header
Amp GND Ground GND GND Common Ground
Speaker (+ / -) Speaker Differential SPK+ / SPK- — Connected across PAM8403 output terminals to 8Ω speaker
